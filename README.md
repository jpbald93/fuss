# Fuss's theorem (Poncelet's porism for quadrilaterals) in Lean 4

A Lean 4 + Mathlib formalisation of **Fuss's theorem** on bicentric quadrilaterals: if a quadrilateral is inscribed in a circle Γ (radius R) and its four side lines are tangent to a circle ω (radius r > 0) whose centre is at distance d ≠ R from the centre of Γ, then `(R² − d²)² = 2r²(R² + d²)`. The converse is proved in the form of **Poncelet's porism** for n = 4: under Fuss's relation the tangent construction closes after four steps, and if ω lies inside Γ, every point of Γ is a vertex of such a quadrilateral.

**Status:** all statements proved, with no `sorry`. `gate.sh` checks 84 named declarations.

## Main statements

| Lean name | File | Statement |
|---|---|---|
| `Fuss.fuss_of_isBicentric` | `Geometry.lean` | forward direction: a bicentric quadrilateral satisfies Fuss's relation (r > 0, d ≠ R) |
| `Fuss.poncelet_chain_closes` | `Porism.lean` | under Fuss's relation a non-stalling tangent chain closes after four steps |
| `Fuss.exists_bicentric_of_fuss` | `Geometry.lean` | ω inside Γ and Fuss's relation ⇒ every point of Γ is a vertex of a bicentric quadrilateral |
| `Fuss.fuss_iff_forall` | `Geometry.lean` | porism: one bicentric quadrilateral ⇔ one through every point ⇔ Fuss's relation |
| `Fuss.fuss_iff_reciprocal` | `Forward.lean` | equivalent form `1/(R−d)² + 1/(R+d)² = 1/r²` |
| `Fuss.nonvacuous` | `Example.lean` | explicit circles satisfying all hypotheses (R = 7, d = 1, r = 24/5) |

"Bicentric" here means four pairwise distinct points on Γ whose four side lines are tangent to ω; convexity of the quadrilateral is not proved. The hypothesis d ≠ R is necessary: `code/check_fuss.py` constructs a crossed example with d = R.

## Verification

`./gate.sh` builds the library and generates its own `#print axioms` queries for the 84 named
declarations (every Lean name cited in the accompanying paper, plus those queried during
development). The queries are generated by the gate itself, not read from a file in the repository.

The gate fails if any of the following is true:
- a source file contains `sorry`, `admit`, `native_decide`, `axiom`, `#eval`, `run_cmd`, `set_option`, `macro`/`elab`/`syntax`/`notation`, or `import Lean`;
- the build fails;
- a named declaration is missing, or has an extra report;
- a named declaration depends on anything other than `propext`, `Classical.choice` and `Quot.sound`.

Output: `PASS (84 declarations, standard axioms only)`.

`tests/tamper.sh` plants six kinds of fake proof in scratch copies and checks that the gate
rejects each one (a rejection must exit nonzero and print the expected `FAIL` message): a `sorry`; an axiom split across two lines; an `#eval` printing a fake axiom
report; a custom macro; a weakened statement (fuss without d ≠ R: false (see the d = R example).); and a genuine extra
axiom with a long name, so that the report wraps over several lines.

`code/` contains independent numerical checks (Python, exact or high-precision arithmetic) of the
identities and of the hypotheses' necessity. `scratch/` contains the `#print axioms` driver file used during development and its recorded
output (`scratch/ax.out`).

## Layers 14 and 15

`Fuss/L14.lean` (37 declarations) restates the main theorems using only Mathlib notions (`EuclideanGeometry.Sphere`, `Sphere.IsTangent`, affine spans) and proves them from this development. Its witness is an explicit bicentric kite in `ℂ` (Γ = (1, 7), ω = (0, 24/5)), and a second configuration shows that neither side of the porism equivalence is constant. `Fuss/L15Classical.lean` (13 theorems) contains classical statements of Fuss's theorem and Poncelet's porism for quadrilaterals written independently from textbook statements by an AI model that did not see this code, reproduced verbatim in the namespace `Fuss.Classical`; its `cov_*_part` theorems prove parts of them from this development. Not proved: convexity of the quadrilaterals produced (the writer's statements require convex quadrilaterals touching ω on the sides), the clause "d = 0 iff the quadrilateral is a square", and 2(a) without the extra hypothesis d < R. None of the writer's statements was shown false. All 50 new declarations are in the gate's list.

## Build

```sh
curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh   # if Lean is not installed
lake exe cache get
lake build
./gate.sh
bash tests/tamper.sh
```

Toolchain: Lean `v4.33.1`, Mathlib `v4.33.1` (revision pinned in `lake-manifest.json`).
